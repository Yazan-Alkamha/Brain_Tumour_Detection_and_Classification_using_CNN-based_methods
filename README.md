# Brain_Tumour_Detection_and_Classification_using_CNN-based_methods

Brain tumor detection and classification using CNN-based methods. This project compares custom CNN models with pre‑trained architectures to evaluate performance, accuracy, and precision as part of my BSc Computer Science dissertation.

## Dataset
This project uses the publicly available *Brain Tumor MRI Dataset* from Kaggle:

https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

The dataset is **not included in this repository** due to its large size and licensing restrictions. Users who wish to run the models locally should download the dataset directly from Kaggle and place it in their working directory following the structure described in the project documentation.
